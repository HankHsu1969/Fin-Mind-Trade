# FinMind 看盤

用 [FinMind API](https://finmindtrade.com/analysis/#/data/api) 做的網頁看盤軟體。預設顯示大盤（加權指數），在搜尋框輸入股票代號或名稱，就會切到該個股的詳細交易資訊。

## 線上使用

直接開啟：https://hankhsu1969.github.io/Fin-Mind-Trade/

## 在自己電腦上啟動

需要 [Node.js](https://nodejs.org/)（不用安裝任何套件）。

- 雙擊 `start.bat`，或
- 在這個資料夾執行 `npm start`（等同 `node server.js --open`）

瀏覽器會自動開啟 http://localhost:8080 。直接用瀏覽器開 `index.html` 也可以運作。

## 功能

**大盤（預設）**：加權指數／櫃買指數切換
- 指數報價：開高低收、漲跌、成交金額、成交筆數、振幅、52 週高低
- K 線圖＋MA5／20／60＋成交金額，可切 1 月／3 月／6 月／1 年／3 年
- 技術指標：KD(9,3,3)、MACD(12,26,9)、RSI(6,12)
- 上市整體三大法人買賣超（億元）、融資融券餘額與券資比、近期行情

**個股**（輸入代號，例如 `2330`、`台積電`）
- 報價：開高低收、成交量（張）、成交金額、本益比、淨值比、殖利率、外資持股比例、52 週高低
- 同樣的 K 線圖與技術指標
- 三大法人買賣超（張），含外資／投信連買連賣天數、近 5／20 日合計
- 融資融券（張）、券資比、資使用率
- 月營收近 12 個月（柱狀圖：當月 vs 去年同月），含月增、年增、今年累計年增、近 12 個月合計與年增
- 營收與毛利：最近四季（過去 12 個月）堆疊柱狀圖，毛利＋營業成本＝營收，柱頂標毛利率（金融業沒有毛利項目）
- EPS：最近五個完整年度＋今年已公布季度，依 Q1～Q4 堆疊的柱狀圖，柱頂為全年 EPS；另有近四季 EPS
- 以上三張圖滑鼠移上去（或用 Tab 鍵）會顯示明細，右上可切換「圖表／表格」
- 日成交明細、近兩日相關新聞

**其他**
- 自選股清單（存在瀏覽器裡），在個股頁按「☆ 加入自選」加入
- 搜尋框支援代號與名稱，可用方向鍵選擇；在頁面上直接打數字也會跳到搜尋框
- 右上角 ↻ 重新抓資料；⚙ 可填入 FinMind API token
- 最上方顯示 FinMind API 剩餘請求次數：有 token 時查 FinMind 帳號的實際用量（`v2/user_info`）；沒有 token 時 FinMind 不提供查詢，改用這個瀏覽器近一小時的請求數估算（上限 300 次/小時）

## 限制

- FinMind 免費版只有**盤後日資料**，不是即時報價。盤中即時、分 K 需要 FinMind 付費等級。
- 不填 token 也能用，但每小時請求次數較少。到 FinMind 免費註冊後取得 token 貼到設定裡，可以提高上限。
- 開一次大盤約 3～4 次請求，開一次個股約 9 次請求；自選股每檔 1 次。同一筆資料 5 分鐘內會用快取。
- 資料僅供參考，不構成投資建議。
